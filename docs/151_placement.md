# 通常版と151匹揃う版の「共通部分」の配置

- 151匹揃う版だけのコード・データは .v151（0x08F80000〜）に置き、通常版と共通の部分の関数・データの場所はすべて同じにしている（通常版で作ったステートを151版で読んでも、RAMに残っている関数ポインタがずれないため）。
- ただし「共通部分は1バイトも変わらない」わけではない。遠い所の関数を呼ぶための中継（veneer、0x0870CA10〜）は、数は同じ（430個）でも並び順が通常版と151版でちがい、それを呼ぶ bl の中身もちがう。関数やデータの場所は同じなので、ゲームの動き・セーブ・ステートには影響しない。
- 並び順がちがうのは、151版のほうがシンボルの数が多く、リンカーが中継を並べる順番が変わるため。直すと通常版の中身も変わるので、直していない。
- 151版のCコード（port/v151/hk_v151.c）は日本版の関数を const の関数ポインタ経由で呼んでいるが、agbcc はこれを直接の bl にしてしまい、中継が3つ増える。この3つは .v151 の中に置かれるので、共通部分の中継の数は変わらない（volatile にして直接呼ばないようにしても、共通部分の並び順は同じようにちがったので、元のままにしている）。
- 確かめ方：両方の版を作り、`arm-none-eabi-nm -n` で 0x08F80000 より前の、名前に veneer を含まないシンボルのアドレスがすべて同じこと、veneer の数が同じことを比べる。
